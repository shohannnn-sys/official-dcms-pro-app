## Dependency and licensing policy

The Phase 0 candidate stack has no manifest or installed project dependencies, so no dependency/license audit has yet been performed. The Phase 12 audit must inventory direct, transitive, build-time and bundled runtime components, font files, icon artwork, generated assets, Windows/WebView2 assumptions and licenses from the exact lockfiles and artifact.

**Default allowlist for review:** MIT, Apache-2.0, BSD-2-Clause/BSD-3-Clause, ISC, CC0/public-domain components, zlib, and OFL-1.1 fonts where obligations are met. Other permissive licenses require legal/owner review. GPL/AGPL, paid/closed SDKs and libraries with runtime subscription/service dependencies are excluded unless a lawyer approves the exact distribution model. License alone does not prove maintenance/security quality.

**Candidate packages/components (unlocked):** Tauri 2 and official plugins; React/React DOM; TypeScript; Vite; Rust stable; SQLite; `rusqlite` or SQLx; SQLCipher Community Edition; Argon2id implementation; Windows DPAPI/WebView2 bindings; a small set of accessible React primitives, forms/query/table/chart utilities if demonstrated necessary; local Noto Sans / Noto Sans Bengali fonts; local PDF/print tooling (prefer WebView2). Version pinning and license scanning happen in Phase 1/12, not by assumption in this discovery document.

**Not allowed:** remote fonts/icons/scripts, paid APIs, cloud databases, telemetry/analytics/ad SDKs, mandatory runtime update endpoints, hidden external fetches, unlicensed copied artwork, direct frontend SQL, broad shell permissions, a package added solely for marketing, or an unreviewed third-party Tauri printer plugin.
