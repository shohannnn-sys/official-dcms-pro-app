# DCMS Pro

DCMS Pro is planned as an offline-first Windows dental-clinic management system for Bangladesh. The repository contains Phase 0 discovery, Phase 1 architecture/design documents, and an isolated non-shipping Windows proof spike; **no production application implementation has begun**.
